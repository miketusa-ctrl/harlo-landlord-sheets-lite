# Harlo Landlord Sheets Lite

Free spreadsheet template for DIY landlords who want a simple rent roll and tenant ledger for a single property.

This is the official GitHub mirror of **Harlo Landlord Sheets Lite**. Paid tiers and add-ons are sold on [Ko-fi](https://ko-fi.com/harlodigital) only.

> Templates, not tax, legal or accounting advice. Consult a CPA/attorney and follow your local landlord-tenant law.

## What’s in Lite

Three tabs in one `.xlsx` workbook:

- **Rent Roll** — units, tenants, monthly rent, paid-this-month, automatic Paid / Partial / Unpaid / Vacant status
- **Tenant Ledger** — charges, payments, late fees and credits with a running balance
- **Disclaimer**

It opens with a fictional example (one property, four units) so the formulas are already working. Swap in your own records. No macros, no scripts, no add-ons.

For multi-property dashboards, late-rent tracking, maintenance, leases, deposits, expenses and inspections, use **Harlo Landlord Sheets Pro**. For larger portfolios (up to 50 units) plus a multi-year dashboard, mileage, capex and vendors, use **Harlo Landlord Sheets Portfolio**.

## How to open it

### Microsoft Excel
1. Download `Harlo-Landlord-Sheets-Lite-v0.1.0.xlsx` from this repository.
2. Open the file in Excel. Keep a backup copy before you replace the sample rows.

### Google Sheets
1. Upload the `.xlsx` to Google Drive (**New → File upload**).
2. Right-click → **Open with → Google Sheets**.
3. **File → Save as Google Sheets** to get a native copy (the original upload stays untouched).
4. Check the sample: Rent Roll shows one property (**Birchwood Fourplex**) with four units — two Paid, one Partial, one Vacant — and Tenant Ledger has running balances for Priya and Marco.
